# Solver-Aware Precision Allocation

**Solver-Aware Precision Allocation Among Stored Observations in Robust Matrix Completion**

Repository website for the project by Nima Sahraneshinsamani, José I. Aliaga, Sandra Catalán, and José R. Herrero.

Project details and resources will be expanded after paper publication.

## Abstract

In robust matrix completion at scale, mixed precision plays two distinct roles: storage precision for observed entries and arithmetic precision for the solver. This project studies solver-aware storage allocation under a robust IRLS framework, isolating storage effects by evaluating allocation and solver arithmetic in FP64.
